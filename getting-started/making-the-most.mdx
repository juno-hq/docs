## The loop

1. Ask your coding agent to [sync](/developer-tools/sync) so Scott can understand recent local agent work.
2. Ask your coding agent to [push](/developer-tools/push) when a focused thread should become a team-readable planspace.
3. Use [comments](/collaboration/comments), [reviews](/collaboration/reviews), and [sharing](/collaboration/sharing) to align the team.
4. Ask your next coding agent to [pull](/developer-tools/pull) when a reviewed planspace is ready for execution.
5. Use the [Scott GitHub App](/developer-tools/github-app) to connect pull requests back to the planspaces that shaped the work.
