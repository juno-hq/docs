## The loop

1. Run [`scott sync`](/developer-tools/sync) so Scott can understand recent local agent work.
2. Run [`scott push`](/developer-tools/push) when a focused agent thread should become a team-readable planspace.
3. Use [comments](/collaboration/comments), [reviews](/collaboration/reviews), and [sharing](/collaboration/sharing) to align the team.
4. Run [`scott pull`](/developer-tools/pull) when a reviewed planspace is ready for execution.
5. Use the [Scott GitHub App](/developer-tools/github-app) to connect pull requests back to the planspaces that shaped the work.
