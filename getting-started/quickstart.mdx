## Install

<AccordionGroup>

  <Accordion title="Browser use (recommended for PM's & designers)" icon="globe">
    Go to [app.tryscott.ai](https://app.tryscott.ai/login) and sign in with Google or GitHub. The browser app uses cloud sandbox execution to make it easier to collaborate with developers on their ideas.
  </Accordion>

  <Accordion title="Desktop app + CLI (recommended for developers)" icon="terminal">
    One command installs both the Scott AI desktop app and the `scott` CLI.
    Zero dependencies — no Homebrew, no npm, no Node. The CLI is a single
    self-contained binary; macOS and Linux are supported out of the box.

    ```bash
    curl -fsSL https://tryscott.ai/install | sh
    ```

    After installing, get going in two commands:

    ```bash
    scott login          # one-time browser auth
    scott setup          # wires Scott into your coding agent
                         # (Claude Code, Cursor, Codex, OpenCode, Gemini)
    ```

    Then in any project, ask your coding agent to "push this conversation
    to Scott" — `scott setup` drops the skills and rule that make agents
    call `scott push` for you. The CLI prints a clickable planspace URL.

    See the full [CLI reference](/developer-tools/cli).
  </Accordion>

</AccordionGroup>



## Set up Scott AI

<AccordionGroup>
  <Accordion title="I'm setting up for my team" icon="users">
    1. **Create an account** — see [Install](#install) above. The browser app is recommended for PM's & designers, we recommend the desktop app + CLI for developers.
    2. **Create a planspace** — name your [planspace](/planspaces/overview) after your next big idea that you have been thinking about
    3. **Attach context** — [connect](/planspaces/connected-sources) your GitHub repo, upload docs, or point to a local folder so the agent can ground its output in your codebase
    4. **Describe what you want to build** — start with a rough prototype from your coding agent, or describe the intent from scratch
    5. **Invite your team to review** — when the idea is more fleshed out, [request reviews](/collaboration/reviews) from your team
    7. **Iterate** - as with all good ideas, iteration and collaboration refines the idea into something great

    <Tip>
      Start with a real project your team is about to begin. The best way to evaluate Scott is with a plan that actually matters.
    </Tip>

    **Next steps:** [Sharing](/collaboration/sharing) · [Reviews](/collaboration/reviews) · [Making the most of Scott AI](/getting-started/making-the-most)
  </Accordion>
