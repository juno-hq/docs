For You is the personal hub inside Scott. It combines notifications, review requests, mentions, invites, and Sync Chat.

## Tabs

| Tab | What it shows |
| --- | --- |
| All | Recent notifications across planspaces |
| Reviews | Open review requests assigned to you |
| Mentions | Comments where someone mentioned you |
| Invites | Planspaces you have been invited to join |
| Sync | Sync Chat over recent local agent history |

## Sync tab

The Sync tab is where `scott sync` sends you. It lets you ask across recent local agent sessions, attach code context, and identify sessions worth turning into planspaces.

Use Sync when:

- you are onboarding Scott
- you want a read across recent agent work
- you need to find promising prototypes or unfinished ideas
- you want Scott to write up a session as a planspace

Learn more in [Sync](/developer-tools/sync).

## Reviews tab

The Reviews tab shows requests where you are the reviewer. Opening a request takes you to the specific document version under review.

From there you can:

- read the document
- inspect comments
- ask review-chat questions
- approve or reject the version

## Mentions and invites

Mentions help teammates pull you into a specific document passage. Invites give you access to planspaces where your feedback or review is needed.

Use For You as the daily triage view: what needs your attention, what needs approval, and which synced sessions are ready to become team context.
