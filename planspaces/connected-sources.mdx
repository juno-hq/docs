Connected sources give the agent access to your existing code, docs, and files so it can generate specs grounded in your actual codebase.

## Source types

### GitHub repositories

Connect a repo and select specific branches. The agent reads the repository contents to understand your codebase structure and patterns.

1. Click **Connect repo** from Sync Chat or the planspace composer
2. Install the Scott GitHub App for the GitHub account or organization you want to use
3. We recommend granting access to all repositories; limiting access can cap answer quality when relevant context lives outside one repo

<Info>
  Scott does not persist repository contents. It fetches code into ephemeral sandboxes only when an answer needs it. If a repository does not appear, reopen **Connect repo** and update the repository access on the Scott GitHub App installation.
</Info>

After installation, the repositories you granted access to appear in Scott's repo picker.

### Uploaded files

Upload files directly — PDFs, design specs, architecture docs, code snippets.

1. Click **Add source** and select **Files**
2. Drag and drop or browse for files

### Local folders (desktop app only)

Point the agent at a directory on your machine.

1. Click **Add source** and select **Local folder**
2. Select the directory

### Google Drive (browser only)

Connect documents from your Google Drive as reference material.

1. Click **Add source** and select **Google Drive**
2. Authorize access and select documents

## Refresh sources

If your code has changed since you attached a source, click **Refresh** to pull in the latest state.

Sources are attached when you [create a planspace](/planspaces/overview) or send a Sync Chat message with selected sources.
